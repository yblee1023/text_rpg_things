# 창귀록 倀鬼錄

조선 초 한양. 몰락 양반 출신 포교 **한서린**이 닷새 안에 여섯 명의 실종을 쫓다가, 자신이 살아 있다는 사실 자체가 그 사건의 시작이었음을 알게 되는 미스터리.

- **단일 HTML 텍스트 게임.** LLM 호출도, 빌드도, 의존성도 없다. 파일 하나를 브라우저로 열면 끝.
- **1회차 40~50분.** 엔딩 8종은 회차 간 도감으로 누적되고, 전부 모으면 프리퀄 「대살록」이 열린다.
- **저장**은 localStorage. 웹에 올려 접속하면 진행이 저장된다.

## 플레이

`changgwirok.html`을 브라우저로 연다. (아이폰에서 파일을 눌러 여는 미리보기 화면은 자바스크립트를 실행하지 않으니, 웹에 올려 Safari 주소창으로 접속하면 된다.)

주소 끝에 `#dev`를 붙이면 엔딩 도감과 프리퀄이 바로 열린다 — 테스트용.

## 규칙

- 닷새, 하루 세 발품. 사람을 만나 **압박·회유·물증 제시**로 심문한다 — 상대마다 통하는 방법이 다르고, 틀리면 단서가 영영 사라진다.
- **신안(神眼)**을 쓰면 상대의 속이 보이지만 **무병(巫病)**이 오른다. 무병은 자원이자 시한폭탄 — 진실을 볼수록 몸이 상하고, 100이면 죽는다. 진엔딩에 서려면 60을 넘어야 한다.
- 밤마다 창귀를 마주보거나, 부적을 태우거나, 그냥 잔다.

## 개발

```sh
node check.mjs
```

의존성 0. `<script>` 블록을 뽑아 컴파일하고, 손으로 깎은 DOM 껍데기에 게임을 부팅해 무작위 300판을 돌리며 크래시·막다른 화면을 찾는다. 좋은 엔딩 게이트(2막 진입, 창귀 해방, 서장 건너뛰기)는 무작위 플레이가 못 밟으므로 지정 검사로 따로 덮는다.
