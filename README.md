# text_rpg_things

순수 스크립트 분기로 돌아가는 텍스트 RPG 모음. 각 게임은 자기 폴더 안에서 완결된다 — 빌드도, 의존성도 없이 HTML 파일 하나면 플레이된다.

## 게임

| 게임 | 설명 |
|---|---|
| [`changgwirok/`](changgwirok/) | **창귀록 倀鬼錄** — 조선 초 한양, 닷새짜리 실종 미스터리. (v2) |
| [`lastroad/`](lastroad/) | **마지막 국도** — 멸망 후 국도를 가로질러 마지막 배까지. 자리는 셋, 태우려는 사람은 넷. |

## 구조

게임 하나당 폴더 하나. 새 게임은 새 폴더로 추가한다.
