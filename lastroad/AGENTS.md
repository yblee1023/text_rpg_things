# lastroad — 마지막 국도

## Purpose

단일 파일 한국어 포스트아포칼립스 로드무비. 죽은 내륙을 가로질러 북항의 마지막 배까지
가는 여정. 차의 자리는 셋, 태우려는 사람은 넷 — **누구를 태우고 갈 것인가**가 게임의 전부다.
순수 스크립트 분기, **LLM 호출 없음·빌드 없음·의존성 없음**. 친구에게 URL만 주면 플레이된다.
1회차 15~25분. 엔딩 7종은 localStorage 도감으로 회차 간 누적된다.

이 게임은 **창귀록의 회고에서 나왔다.** 창귀록에서 밟은 지뢰들을 설계 단계에서 구조적으로
피하는 것이 명시적 목표였고, 그 각각을 `check.mjs`가 회귀 가드로 지킨다(아래 표).

### Common Patterns

- **모든 화면은 `show(nodes, choices)`** (L~115). `nodes`는 `[[cssClass|null, html], …]`,
  `choices`는 `[{k:'라벨', t:'설명', f:핸들러, cls?, off?}]`. 씬 함수는 `show()`를 부르고 끝난다.
  핸들러가 다음 씬을 몬다. 라우터·상태머신 없다.
- `paint()` (L~95)가 매 `show()`마다 HUD를 `S`에서 다시 그린다. HUD DOM을 직접 만지지 마라.
- **여정 루프는 `leg → 인카운터 → onward() → drive() → leg`** 로 수렴한다.
  `drive()`가 연료·식량·거리를 정산하고 실패/도착을 판정한다. **모든 씬은 반드시 버튼을 준다** — 빈 화면은 크래시로 취급된다.
- 노드 클래스: `hd`(머리), `sp`(강조·닫는 줄), `said`(대사), null(평문), `note`(회색 메타).
- 데이터는 최상위 테이블에: `COMP`(동승자), `PLACES`, `ENC`(인카운터 풀), `EPI`(동승자별 작별 문구), `ENDINGS`. **씬이 아니라 테이블을 고쳐라.**
- 인카운터를 추가하려면 `ENC` 배열에 `{id, f, when?, repeat?, join?, late?, w?}` 객체 하나를 넣는다.
  씬 함수 `f`는 반드시 `onward`(또는 `end`)로 수렴해야 한다.

### State

`S`는 `INIT()` 한 곳에서만 만들어진다. **필드를 늘리면 `INIT()`만 고친다** — 단, Set이면 `SETS`에도 넣어라.
`S`는 `let`이고 `boot()`/`crash()`가 재할당하므로, 씬을 넘겨 사는 지역변수에 캐시하지 마라.

```js
S = { dist, fuel, food, hope,   // 자원 — 각기 다른 실패 경로
      party[], met:Set, fate{}, // 동승자·이력·개별 결말 태그
      flags:Set, leg, hungry, used:Set, begun, over };
```

**좌석 불변식**: `S.party.length <= SEATS`(=3). `offerSeat()`가 만석일 때 교환 딜레마를 강제해 이 불변식을 지킨다. 새 합류 경로를 만들면 반드시 `offerSeat()`를 거쳐라 — 직접 `party.push` 금지.

### Save Keys

`lastroad.endings.v1` — 엔딩 도감(문자열 배열)만. 진행 세이브는 없다.
`ENDINGS`에 엔딩을 추가하면 `end()`에 같은 key의 `case`를, `markSeen`을 부르는 경로를 함께 넣어야 도감이 샌다(`엔딩 도감 키와 end() 분기가 정확히 일치한다`가 잡는다).

## Known Limits

- `check.mjs`는 **형식·도달성·무크래시만** 보증한다. 프로즈가 진부한지, 톤이 맞는지, HUD가 예쁜지는 사람이 브라우저로 봐야 한다. (창귀록과 같은 한계.)
- 밸런스(연료/희망 압박의 체감 난이도)는 사람 완주 플레이테스트로만 확정된다. 무작위 500판은 크래시만 본다.
- 인카운터 프로즈는 짧게 유지했다(2~4노드). 서사 깊이는 창귀록보다 얕다 — 의도된 트레이드오프(짧은 회차·높은 재플레이).
