# 마지막 국도

바다가 죽고 하늘이 내려앉은 뒤, 북쪽 항구에서 마지막 배가 떠난다는 소문. 죽은 국도를
가로질러 그 부두까지 간다. **차의 자리는 셋, 태우려는 사람은 넷.** 태울수록 연료가 빨리
준다. 살아남는 것과 사람으로 남는 것 사이에서, 매 경유지마다 누구를 태울지 고른다.

- **단일 HTML 텍스트 게임.** LLM 호출도, 빌드도, 의존성도 없다. 파일 하나를 브라우저로 열면 끝.
- **1회차 15~25분.** 엔딩 7종은 회차 간 도감으로 누적된다.
- **여정은 매번 다르다.** 중간 경유지의 사건은 풀에서 무작위로 뽑힌다.

## 플레이

`lastroad.html`을 브라우저로 연다. (아이폰에서 파일 미리보기로 여는 화면은 자바스크립트를
실행하지 않으니, 웹에 올려 Safari 주소창으로 접속하면 된다.)

주소 끝에 `#dev`를 붙이면 엔딩 도감이 전부 열린 채로 시작한다 — 테스트용(도감을 저장하지 않는다).

## 규칙

- **연료·식량·희망** 셋을 관리한다. 연료가 0이면 국도에서 멈춘다. 굶주림이 오래되면 희망이
  깎이고, 희망이 0이면 사람들이 흩어진다.
- 경유지마다 사람을 만난다 — **태우거나, 지나친다.** 자리가 차 있으면 누군가를 내려야 태운다.
- 정비공·아이·의사·군인, 넷 다 태울 수는 없다. 누구를 태웠는지가 마지막 부두에서 값을 한다.
- 배는 소문일지도 모른다. 골짜기에 남는 길도, 자리를 내주고 부두에 남는 길도 있다.

## 개발

```sh
node check.mjs
```

의존성 0. `<script>` 블록을 뽑아 컴파일하고, 손수 깎은 DOM 껍데기에 게임을 부팅해
**무작위 500판**을 돌리며 크래시·막다른 화면·좌석 초과를 찾는다. 무작위 플레이가 못 밟는
좋은 엔딩은 **7종 각각을 직접 구동**해 도달성을 따로 증명한다.

이 게임은 창귀록 작업의 회고에서 나왔다 — 그때 밟은 지뢰(취약한 자원 예산, 죽은 분기,
반영 없는 상태값, 조용한 소프트락, 세이브 스키마 버그)를 설계 단계에서 구조적으로 피했고,
그 각각을 `check.mjs`가 회귀 가드로 지킨다. 자세한 매핑은 `AGENTS.md`.

| 파일 | 내용 |
|---|---|
| `lastroad.html` | 게임 전체 (단일 파일, ~690줄) |
| `check.mjs` | 자체 점검 (의존성 0, 18개 검사) |
| `AGENTS.md` | 구조·패턴·상태 관리 + 창귀록 지뢰 방어 매핑 |
