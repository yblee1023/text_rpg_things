# 식죄자 食罪者

사람이 나쁘게 죽으면 시신 앞에 상을 차리고 당신을 부른다. 그 상을 먹으면 죽은 이의 죄가
당신에게 옮는다. 죽은 이는 가벼워지고 당신은 무거워진다. 겨울 한 철, 여섯 번의 상.

- **단일 HTML 텍스트 RPG.** LLM 호출도, 빌드도, 의존성도 없다. 파일 하나를 브라우저로 열면 끝.
- **1회차 10~15분.** 결말 5종은 회차 간 기록으로 누적된다.
- **회차마다 다른 게임이 된다.** 무엇을 먼저 졌느냐에 따라 다음 방에서 보이는 것이 달라진다.

## 이 게임의 규칙 하나

**죄를 지지 않은 자는 죄를 알아보지 못한다.**

당신이 짊어진 다섯 죄가 곧 능력치이자 지각의 렌즈다. 노(怒)가 없으면 벽에 남은 주먹 자국이
화면에 **아예 뜨지 않는다.** 탐(貪)이 있어야 말(斗) 밑바닥에 덧댄 나무가 보인다.

그래서 일을 잘하려면 죄를 져야 하고, 죄를 지면 사람에서 멀어진다. 업(業)이 15에 닿으면
당신은 사람으로 남지 못한다.

## 플레이

`sikjoeja.html`을 브라우저로 연다. (아이폰에서 파일 미리보기로 여는 화면은 자바스크립트를
실행하지 않으니, 웹에 올려 Safari 주소창으로 접속하면 된다.)

주소 끝에 `#dev`를 붙이면 결말 기록이 전부 열린 채로 시작한다 — 테스트용(기록을 저장하지 않는다).

## 한 상의 흐름

1. **도착** — 마을이 부른다. 죄가 있으면 도착하자마자 보이는 것이 다르다.
2. **살핀다** — 네 군데 중 **두 군데만.** 주의는 유한하다. 각 자리에서 당신의 죄가 본 것이 따로 뜬다.
3. **상을 받는다** — 셋 중 하나.
   - **다 먹는다** — 죽은 이는 편히 간다. 업이 크게 오른다.
   - **한 죄만 골라 먹는다** — 그것이 가장 무거웠다면 그 사람은 가고 업은 덜 오른다. 틀리면 못 간다.
   - **물린다** — 아무것도 지지 않는다. 그 사람은 남는다.
4. **떠난다** — 지고 온 죄가 다음 마을의 시야를 바꾼다.

죄가 3에 닿으면 그 죄가 장면에 끼어들어 말을 걸기 시작한다.

## 개발

```sh
node check.mjs
```

의존성 0. 22개 검사. `<script>`를 뽑아 컴파일하고, 손수 깎은 DOM 껍데기에 부팅해 무작위
400판으로 크래시·막다른 화면을 찾고, **결말 5종을 상태 주입이 아니라 실제 플레이로** 도달시킨다.

RPG 조건 자체도 검사한다 — 죄 0일 때와 죄를 다 졌을 때 같은 자리에서 보이는 줄 수가
다른지, 모든 상의 정답을 읽어낼 단서가 실제로 있는지, 정답이 HUD나 선택지 문구로 새지 않는지.
